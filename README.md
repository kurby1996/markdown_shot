# 📸 Markdown 视频课程截图助手 (Web 控制台版)

专为**视频课程学习、网课跟学、技术教程记录**量身打造的自动化 Markdown 截图与笔记工具。

边看视频边按快捷键，截取的图片**自动保存到指定目录并无缝追加到目标 Markdown 笔记文件末尾**，无需频繁手动复制粘贴切屏！

---

## ✨ 核心特性

- 🎯 **多种截图模式**：
  - **选区划选与 Snipaste 式专业标注**（默认 `Alt + Q`）：
    - 冻结屏幕并自由拖拽选区，显示实时像素尺寸。
    - **🔲 矩形框**：突出重要代码、要点或区域（快捷键 `1`/`R`）。
    - **⭕ 圆形/椭圆**：圈画核心参数或关键图标（快捷键 `2`/`O`）。
    - **↗️ 箭头**：指引视线、标注流程或示意（快捷键 `3`/`A`）。
    - **✏️ 画笔/涂鸦**：自由手绘线条、勾画重点（快捷键 `4`）。
    - **🔤 文字标注**：点击直接在图片任意位置输入说明文字（快捷键 `5`/`T`）。
    - **🎨 8色调色盘 + 3档粗细**：随心切换红/橙/黄/绿/蓝/紫/白/黑与粗细。
    - **↩️ 撤销与重做**：支持 `Ctrl+Z` 撤销、`Ctrl+Y` 重做与一键清空。
    - **📋 复制到剪贴板**：支持 `Ctrl+C` 仅复制标注后的图片，灵活粘贴到聊天或文档。
    - **✔ 保存追加**：按 `Enter` 或双击完成截图并自动保存追加到 Markdown。
  - **全屏快速秒截**（默认 `F9`）：不中断视频播放，按下瞬间完成全屏截图并存入文档。
  - **活动窗口截图**（默认 `Alt + W`）：精准自动捕获正在播放视频的播放器或浏览器窗口。
  - **剪贴板自动监听**：开启后，使用微信截图 (`Alt+A`)、Snipaste (`F1`) 或 `Win+Shift+S` 复制的图片均会自动存入 Markdown！
- ⌨️ **快捷键任意自定义**：
  - 网页控制台内置**可视化按键录制器**，点击“按键录制”并在键盘按下组合键即可一键修改！
  - 无需重启服务，全局快捷键实时热更新生效。
- 📁 **目标 Markdown 文件与路径灵活配置**：
  - 支持**系统文件选择弹窗**，一键选择本地任意 `.md` 文件或一键新建课程笔记。
  - **图片存储策略**可自定义：
    - 相对目录模式（推荐）：自动保存在 `.md` 所在目录下的 `assets/` 或 `images/` 子文件夹中。
    - 绝对目录模式：保存到指定自定义文件夹。
  - 自动计算并生成规范的 Markdown 相对图片链接（完美兼容 **Typora、Obsidian、VS Code、Notion、GitHub** 等）。
- 📝 **Markdown 模板高度自定义**：
  - 支持自定义追加格式，支持 `{image_path}`、`{filename}`、`{timestamp}`、`{index}`、`{note}` 等占位符。
- 🌐 **现代化 Web 交互控制台**：
  - **最新截图流**：实时展示最近截图卡片、缩略图、尺寸大小与时间。
  - **即时备注回写**：在网页卡片直接输入备注并回车，自动同步修改对应 Markdown 里的注释！
  - **双向实时文档查看**：支持“实时渲染预览”与“源码编辑”，并支持一键在本地外部编辑器打开。
  - **明暗主题**：一键切换暗黑模式与明亮模式。
  - **提示音与桌面通知**：截图成功播放清脆提示音，无需切屏即可确认已保存。

## 🚀 快速启动

### 方法一：Windows 一键启动（推荐）
在项目根目录下，双击运行 **`start.bat`** 即可。脚本将自动检查依赖并在默认浏览器中打开控制台：
```
http://127.0.0.1:5000
```

### 方法二：命令行启动
```bash
# 1. 安装依赖（首次运行）
pip install -r requirements.txt

# 2. 启动服务
python run.py
```
启动成功后，浏览器会自动打开 `http://127.0.0.1:5000`。

## 📖 使用指南

### 1. 观看课程并截取重点
1. 打开你要学习的视频课程（B站、腾讯课堂、YouTube、PotPlayer、网易云课堂等）。
2. 在任意时刻按下快捷键：
   - 按 **`Alt + Q`**：屏幕静止并进入选区截图，拖动鼠标划选视频区域，按 `Enter` 或双击完成截图。
   - 按 **`F9`**：直接对当前全屏进行快照并存入笔记。
3. 截图完成后，系统会播放轻柔提示音，并在目标 Markdown 文档末尾自动追加类似以下内容：

```markdown
### 📸 截图 1 - 2026-08-25 21:10:00
![course_20260825_211000_123.png](assets/course_20260825_211000_123.png)
> 📝 **备注**: 老师讲解的核心架构图
```

### 2. 在 Web 控制台更改快捷键
1. 打开网页控制台，点击右上角的 **⚙️ 设置** 按钮。
2. 切换到 **“⌨️ 快捷键自定义”** 标签页。
3. 点击你想更改项右侧的 **“按键录制”** 按钮。
4. 在键盘上按下你习惯的快捷键（如 `Ctrl + Alt + A` 或 `Alt + S` 或 `F8`）。
5. 点击底部的 **“💾 保存并应用配置”**，全局热键即刻更新！

### 3. 配置或更换目标 Markdown 文件
1. 在网页顶部点击当前文件名，或进入设置中心的 **“📁 目标文档与存储”**。
2. 点击 **“📁 浏览选择”**，在系统弹窗中选择你想记录的 `.md` 文件；或点击 **“➕ 新建”** 快速创建新课程笔记。
3. 随时可以在控制台点击 **“🚀 本地编辑器打开”**，使用你电脑上的 Typora 或 VS Code 查看完整笔记。

## ❓ 常见问题

**Q: 快捷键在全屏播放视频或其他窗口时有效吗？**  
A: 是的！本工具采用 Windows 底层全局热键监听，无论你在全屏播放器、浏览器标签页还是写代码，快捷键都能在后台直接响应。

**Q: 截图保存在哪里？移到其他电脑上图片会失效吗？**  
A: 默认保存在 Markdown 文件同级的 `assets/` 文件夹中，Markdown 内部引用的是标准的相对路径（如 `assets/course_xxx.png`）。只要将笔记文件和 `assets` 文件夹一起移动或打包，在任何 Markdown 编辑器（Typora、Obsidian、VS Code 等）中均能完美显示。

**Q: 如何与外部截图软件配合？**  
A: 进入设置 -> “🔔 体验与通知” -> 勾选 **“📋 剪贴板图片自动追加监听”**。勾选后，使用微信截图、Snipaste、QQ截图或 Windows 自带 `Win+Shift+S` 截图复制后，工具会自动将剪贴板的图片存入 Markdown！
